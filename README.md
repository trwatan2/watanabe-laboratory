## GitHubで更新する方法
1. このフォルダの中身をリポジトリの**一番上（root）**にアップロードします。
2. 既存ファイルがある場合は、同名ファイルを置き換えて Commit changes します。
3. GitHub Pages は `main` / `/(root)` のままで自動再公開されます。
4. 通常は1〜2分後にサイトへ反映されます。
