Researchページ修正版（2026-09-11）

修正内容
・トップとResearchを同じ4テーマ、同じ順番・見出し・概要・動画に統一。
・各テーマに「研究のねらい」「主な研究項目」「関連論文」を追加。
・任意の説明、図、動画、研究成果を後から追記できる構成。
・古い research.html#electrified は e-Reaction の説明へ接続。

反映方法
1. ZIPを解凍する。
2. GitHubの trwatan2/watanabe-laboratory を開き、Add file → Upload files を選ぶ。
3. 解凍したフォルダの中身（index.html、research.html、assets、css、data、scripts、RESEARCH-EDITING.md）をドラッグする。
   research-updateという外側のフォルダごとは入れない。
   フォルダはドラッグして入れると、中の階層が維持される。
4. Commit changesで保存する。
5. 公開処理が完了してからResearchページを再読み込みする。

既存ファイルを削除する必要はない。ファイル名は index.html と research.html のまま使用する。
トップページについては「5つの研究テーマ」を「4つの研究テーマ」に修正した。
今後の追記方法は RESEARCH-EDITING.md に記載してある。
